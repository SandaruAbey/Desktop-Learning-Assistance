# Student AI Assistant

An intelligent assistant application designed to help students with their academic tasks and everyday needs. This Python-based project uses advanced OCR and AI-powered chat functionalities to make student life easier.

---

## 🚀 Features
- **AI Chat**: Communicate with the assistant for instant responses and solutions.
- **Document Upload**: Upload files for OCR processing and text extraction.
- **Tesseract OCR Integration**: Converts images or PDFs into readable text format.

---

## 🛠️ Technologies Used
- **Python**: Core programming language.
- **Tesseract-OCR**: Optical Character Recognition for document processing.
- **tkinter**: Graphical User Interface library for Python.
- **Genai**:  Enables intelligent, context-aware responses
---

## 📋 Requirements
### Prerequisites
Make sure you have the following installed:
- Python 3.9+ (or compatible version)
- Tesseract-OCR ([Download Here](https://github.com/tesseract-ocr/tesseract))
- Pip package manager

### Python Dependencies
Install the required Python libraries using:

# Install ttk themes
pip install ttkthemes

# Install emoji
pip install emoji

# Install PyMuPDF
pip install pymupdf

# Install Google's Generative AI library
pip install google-generativeai

# Install Deep Translator
pip install deep-translator

# Install pytesseract
pip install pytesseract

# Install Pillow (PIL fork)
pip install pillow

#🔧 Setup and Usage
1. Install Dependencies
2. Download Tesseract-OCR ([Download Here](https://github.com/tesseract-ocr/tesseract))
3. pytesseract.pytesseract.tesseract_cmd = r"C:\Program Files\Tesseract-OCR\tesseract.exe"
4. Run the Application -> python StudentAIAssistant.py

# Exporting to .exe (Optional)
1. pip install pyinstaller
2. pyinstaller --onefile --windowed learningAI.py
